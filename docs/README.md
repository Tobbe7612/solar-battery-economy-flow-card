# Project Documentation

This directory contains the project's durable technical memory.

## Files

### `PROJECT_HANDOFF.md`
Primary project-specific handoff. Read this first when starting a new development chat, onboarding, returning after a long break, or making architectural changes.

### `ARCHITECTURE_NOTES.md`
Architecture reference for data flow, graph logic, rendering, layouts, assets, and device architecture.

### `DEVELOPMENT_WORKFLOW.md`
Normal development and debugging process.

### `RELEASE_CHECKLIST.md`
Release, GitHub, HACS, and Home Assistant verification checklist.

### `AI_HANDOFF_TEMPLATE.md`
Generic template for future projects. Copy it into a new repository and adapt it.

## Recommended reading order

```text
1. PROJECT_HANDOFF.md
2. ARCHITECTURE_NOTES.md
3. DEVELOPMENT_WORKFLOW.md
4. Relevant source files
5. RELEASE_CHECKLIST.md when preparing a release
```

## Principle

The repository should contain the durable truth.

Chat history can explain why a decision was made, but important technical decisions and lessons should be written here so they survive future chat changes.
